# 失败条件化 Attention Map：第一版实施方案

2026-10-23，协议 attentionmap_v1。

一句话：给定失败结果，让模型学习“应沿哪些步骤关系回看”，并把关系证据与每一步自身的错误证据合起来定位根因。

原来的步骤依赖图回答“哪些步骤可能用到了前面的信息”。新表示回答“为了解释这次失败，后一步应重点回看哪些前面的步骤”。同一条轨迹面对不同失败，可以形成不同关系权重。矩阵行是被解释的后续步骤 j，列是被回看的早期步骤 i；A[j,i] 表示诊断聚合权重，i≤j。旧边是可学习的加分项，未连边位置仍能获得权重。

## 输入和计算

输入 X 是步骤×特征矩阵，每步保留 decision/action 与 observation 的独立文本向量、与任务/失败文本的交互，以及语义、anchor、clue、已有局部错误评分 q、缺失标记和位置特征。F 是任务与首条失败测试的表示。第一版采用固定128维 signed hashing 文本编码，完整扫描文本，训练32维的小模块。文本编码和特征提取不使用标签，也不需要新API请求。

1. h_i=G(X_i)，f=H(F)。单步分支输出 u_i=MLP(h_i,f,h_i⊙f)。
2. Q_j=W_Qh_j+U_Qf，K_i=W_Kh_i+U_Kf。
3. A[j,i]=softmax_i(Q_j K_i/√d + β E[j,i] − softplus(δ)·(j−i)/T)，i≤j。E是已有依赖，β可训练；自环保留。
4. 失败种子 p_j=softmax_j(MLP_seed(h_j,f,h_j⊙f))。用 Aᵀ把种子及后续证据分配给早期步骤；上下文 m_i 是按 p_j A[j,i] 加权的后续步骤值向量。
5. 最终分数 s_i=u_i+MLP_relation(m_i,h_i⊙m_i,log(1+T·Σ_j p_j A[j,i]))。单步分支始终保留，旧图缺边不会将 u_i 清零。

训练采用每条轨迹的列表排序交叉熵。测试时不读取根因步骤、failure_reason或gold_patch。导出A、p、单步分数、关系增量和最终排序，热图与原步骤ID对应。

## 本轮固定实验

数据：RootSE 102条；从既有Qwen nonthinking构图和局部评分缓存读取输入。失败上下文采用postmortem首条测试。q沿用既有introduced且未恢复评分，并提供缺失标记。已有图复用rootse-ours-qwen38-nothinking-causal-v1，q复用rootse-influence-qwen38-nothinking-v3。新增模型调用为0。

划分：按仓库及同任务关系联合分组，5折外部交叉验证；同仓库、同任务的轨迹不跨训练/评估。固定3个种子17/29/43、40轮、AdamW lr=0.001、weight_decay=0.001、每8轨迹更新、梯度裁剪1.0。所有方法相同折、输入、训练轮数。全102条已在历史开发中使用，本轮结果记作分组交叉验证开发实验。

对照：固定上游RRF（复用本地图）；q-only；线性排序；无关系MLP；只沿固定边的attention；无失败条件的稠密attention；失败条件化稠密attention；去图先验的稠密attention。无图版本不输入PageRank/path特征。无失败条件消融仅移除关系模块的F注入，单步评分仍能看失败文本。

指标：Top-1/3/5、MRR；3种子各自结果与均值；相对MLP的新增/丢失命中；按仓库组重采样区间。机制检查：测试时打乱每行允许位置的attention权重；删去50%/100%旧边；根因在旧传播分数为0的子集单独统计。固定图与稠密图均使用相同输入和参数规模。

本轮先检查：attention map是否确实接入排序；缺边位置能否获得非零权重；模型是否超出同输入MLP；关系打乱是否改变排序；旧不可达根因是否被重新找回。

## 研究问题

RQ1：学习失败相关步骤关系，能否提高跨仓库的根因排序？
RQ2：允许补边与保留单步证据，各自对原图不可达根因有多少贡献？
RQ3：失败条件与关系结构对结果的贡献是多少，模型成本和稳定性如何？

独立泛化、语义编码升级和受控重执行留在后续实验阶段；当前实现对应上述完整首轮开发实验。

## 方法依据

Graphormer §3把结构信息作为attention偏置；本方案使用已有步骤边作为软偏置。[论文](https://proceedings.neurips.cc/paper/2021/file/f1c1592588411002af340cbaedd6fc33-Paper.pdf)

GraphTracer §3–4以信息依赖组织Agent失败追踪。本方案聚焦失败条件下可补边的关系与单步残差，两者通过同输入对照检查。[论文](https://arxiv.org/html/2510.10581v1)
