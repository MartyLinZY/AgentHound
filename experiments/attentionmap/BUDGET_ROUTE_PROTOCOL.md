# 按长度触发的完整阅读规则

2026-10-29，RootSE v4 已完成并已查看；Who&When 仍在运行，尚未读取其模型排名或效果。此规则在外部效果计算前冻结，作为追加的输入自适应策略评估。

选择规则：若完整轨迹的 cl100k context tokens ≤16384，使用 full 请求；否则使用 balanced 请求。共同 task、诊断说明仍不计入 context budget，完全沿用主实验口径。不读根因标签、模型回答或置信度，不改变请求文本与输出候选数。选择后的全部请求满足相同 16K 上下文上限。

该数据已对 full 和 balanced 实际调用同一模型、使用相同诊断指令，因此可以按事先保存的输入路由直接重放对应响应。每条部署时仍只需一次调用；追加评估新增 API 调用为 0。此策略的分数是既有同批次请求的组合评估，不称为独立的第四次随机重复。主要三条件与八项 Holm 检验保持原样，策略对比作为追加结果单列。

动机：外部数据的165条记录在原两种预算方法中产生相同请求，而且单节点上限可能在整条轨迹仍能装入预算时就省略原文。短轨迹用全文使压缩信息损失为零；长轨迹用 attention map 分配阅读空间。是否提高诊断正确率由实际响应评估，不由完整性直接推断。

本轮只对 Who&When 做此重放评估。RootSE 的历史 full 提示与当前 aligned 提示不同，不拼接历史 full 结果冒充该策略的新实验。
