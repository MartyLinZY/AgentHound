# Attention Map 语义版本：实验对比

已在新分支 `codex/attentionmap-semantic-20261027` 完成实现和实验。基于 `4a82c4e`，实现与预先固定协议提交为 `cac6870`。

**更换为冻结语义表示后，Attention map 的 Top-1 从 19.93% 提高到 28.43%，Top-5 从 55.23% 提高到 74.84%。** 三个种子分别命中 27、28、32 条；旧版为 21、20、20 条。

| 方法 | Top-1 | Top-5 | MRR |
|---|---:|---:|---:|
| 原词法 Attention map | 19.93% | 55.23% | 0.3650 |
| 语义线性排序 | 24.18% | 75.49% | 0.4606 |
| 语义 MLP | 24.51% | 64.71% | 0.4327 |
| 语义固定图 attention | 27.45% | 66.67% | 0.4503 |
| 语义 Attention map | 28.43% | 74.84% | 0.4741 |
| 语义 attention：关系不注入失败 | 29.74% | 75.49% | 0.4836 |
| 固定 RRF | 26.47% | 49.02% | 0.3952 |

本轮所有学习方法使用同样的 102 条轨迹、35 个仓库/任务组、5 折和 3 个种子。冻结 MiniLM 在本机分块编码全文，并通过固定投影保持 128 维；新旧对应模型的参数量、初始化、40 轮训练、数值特征和图输入相同。两组共完成 180 次训练。

本轮的主要判断：

- 六个模型替换语义表示后，Top-1 均上升。表示质量值得保留为下一轮的基础。
- 语义 attention 相对同输入 MLP 提高 3.92 个百分点，相对固定图提高 0.98 个百分点；打乱 attention 后 Top-5 从 74.84% 降至 66.67%。关系对候选覆盖的作用比首位定位更明显。
- 关系模块不注入失败条件时，Top-1 达到 29.74%；单步评分和诊断种子仍使用失败信息。下一轮优先比较这一简化关系模块。
- 图先验的效果需要分开理解：去图先验重新训练为 26.47%；完整模型在测试时删去全部旧边为 30.07%。两项对应不同的训练条件，应继续检查模型怎样利用旧边。

旧传播为零的 54 条中，语义 attention 平均命中 17 条，旧词法 attention 为 11.67 条，同输入语义 MLP 为 14 条。

按仓库/任务组计算，主比较的 Top-1 增量为 +8.50 个百分点，95% bootstrap 区间为 −3.00 至 +16.50；与 MLP 的增量区间为 −2.75 至 +10.19。下一项验证是固定这些版本，在新任务上比较跨仓库提升。

沿用上轮 sepal_ui #646 案例：两种 attention 都将根因第 13 步排在第一；语义 MLP 从第 2 提升到第 1。该案例用来展示表示与矩阵的变化，全量表现以对照表为准。

验证完成：174 项测试通过；词法重跑的 1,836 份预测及扰动分数与旧版完全一致；全部 3,672 份保存模型预测与 2,448 张矩阵重放一致；旧实验 1,629 个文件及 510 份来源哈希不变。编码约 271.6 秒，两组训练累计约 479.9 秒，新增推理 API 请求为 0。

重复运行已验证：12,905 个编码、特征、模型和预测文件哈希保持一致，新增编码批次与训练次数均为 0。

复现命令：`bash scripts/reproduce_attentionmap_semantic.sh`。实验是既有 RootSE 的分组开发比较，原 RQ 中的新任务评估、受控修改验证关系、等总预算比较继续保留。
